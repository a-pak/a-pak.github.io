Giving new life to an old laptop.

Overview

From spare machine to homelab

I had an old laptop laying around, and I was wondering what I could do with it instead of throwing it in SER waste. I already had personal projects running, but with very limited free-tier cloud compute and storage.

The laptop had 500 GB of storage, a 4-core Intel Pentium, and 8 GB of RAM. I wiped Windows 8, installed Ubuntu LTS Server from a USB stick, and suddenly the machine was usable again. I already had Dockerized projects such as Happy Pour and this website — the one you are reading now.

Stack

  • Ubuntu Server
  • Nginx reverse proxy
  • Docker
  • PostgreSQL
  • DuckDNS + Let’s Encrypt
  • WireGuard VPN
